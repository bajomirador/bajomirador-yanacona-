# Página web administrable de Bajo Mirador Yanacona

Esta versión incluye un panel de administración con Decap CMS.

## Acceso futuro

Una vez configurado el acceso OAuth de GitHub en Netlify:

`https://bajomiradoryanacona.netlify.app/admin/`

Desde el panel se podrán editar textos, proyectos, datos de contacto y subir fotografías.

## Archivos importantes

- `admin/index.html`: abre el panel.
- `admin/config.yml`: define los campos editables y la conexión con GitHub.
- `content/site.json`: guarda el contenido que se edita desde el panel.
- `images/uploads/`: almacena las fotografías subidas.
