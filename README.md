# Sitio web – Comunidad Indígena Bajo Mirador Yanacona

## Cómo abrirlo

1. Descomprime la carpeta.
2. Abre el archivo `index.html` con Google Chrome o Microsoft Edge.

## Cómo cambiar correo y WhatsApp

Abre `config.js` con Bloc de notas y reemplaza:

- `comunidad@ejemplo.org`
- `Agregar número oficial`

Guarda el archivo y vuelve a abrir la página.

## Cómo cambiar textos

Abre `index.html` con Bloc de notas o Visual Studio Code. Los textos se pueden editar directamente.

## Publicación gratuita recomendada

La carpeta puede subirse directamente a:

- Netlify
- Cloudflare Pages
- GitHub Pages

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: diseño visual.
- `script.js`: menú y formulario.
- `config.js`: datos de contacto editables.

Nota: la imagen principal se carga desde Unsplash y requiere conexión a internet. El resto del sitio funciona sin servidor.


## Fotos agregadas

Se agregó una sección de galería con 4 fotos ilustrativas:
- bosque tropical
- fuentes hídricas
- participación comunitaria
- saberes ancestrales

Si luego tienes fotos reales de la comunidad, se pueden reemplazar editando las líneas `src="..."` de las imágenes dentro de la sección `Galería` en `index.html`.
